# Локальная сборка виджета с ресурсами HONOR

Это **личная локальная сборка** (APK лежит в `local-artifacts/`, каталог в `.gitignore`).
Проприетарные шрифты и иконки HONOR **не публикуются** в GitHub — в репозитории остаётся
только код с fallback-ресурсами.

## Что используется

- часы: `Honor-digit-light.otf` (из `/system/fonts` телефона);
- остальной текст: `HONORSansVFNormal.ttf`;
- иконки погоды: drawable `bg_remote_views_sun/cloud/cloud_dark/rain/snow/fog_haze/star`
  из `HnWeatherClock.apk` (`com.hihonor.android.totemweather`), извлечены локально;
- layout повторяет дизайн-код оригинала: прозрачная карточка 4×2, паддинги **16/12 dp**,
  часы **50 dp** тонким шрифтом, дата с отступом **2 dp**, город/погода справа.

## Как собрано

Ассеты лежат в `android/app/src/localHonor/res/` (в `.gitignore`). Gradle подключает
каталог к `main` source set, только если он существует:

```kotlin
val localHonorRes = file("src/localHonor/res")
if (localHonorRes.isDirectory) sourceSets["main"].res.srcDir(localHonorRes)
```

Код выбирает layout/иконки в рантайме через `resources.getIdentifier(...)`:
если локальных ресурсов нет (CI, GitHub-сборка), используется обычный layout и
векторные иконки из `main/res`.

Сборка и установка:

```bash
cd android
./gradlew assembleRelease
adb install -r app/build/outputs/apk/release/app-release.apk
# город для погоды (можно и в настройках приложения):
adb shell "am start -n ru.netmon.android/.MainActivity --es widget_city 'Лесные Поляны'"
```

## Погода

Данные — Open-Meteo (температура/код погоды), город задаётся вручную в настройках
приложения (кнопка «Сохранить город»), иначе определяется по IP. Системный погодный
провайдер HONOR приватный и не вызывается; иконки/типографика при этом — из HONOR.

## Ограничения

- Это не побайтовая копия: RemoteViews не позволяет повторить все эффекты оригинала,
  а шрифт/иконки используются локально.
- Не коммитьте `android/app/src/localHonor/` и `local-artifacts/` — они в `.gitignore`.

## Расположение как в оригинале

```
Лесные Поляны            [иконка] 0°
23:07                    Облачно
Ср, 11.11
```

- город — сверху слева, часы — ниже, дата — ниже часов; погода справа по центру;
- высота виджета — **100 dp** (значение HONOR для этого провайдера);
- Android задаёт размер виджета **ячейками сетки**, поэтому старый экземпляр
  сохраняет прежний размер: удалите его и добавьте заново (кнопка в настройках приложения).

## Геопозиция и дата

- Город: сначала GPS/сеть (`ACCESS_COARSE/FINE_LOCATION`), затем сохранённый город,
  затем IP. Если обратный геокодер отдаёт «городской округ/район», показывается
  сохранённое имя («Лесные Поляны»), а координаты остаются из GPS.
- Дата: `11 ноября Ср` (без года).
- Город: 13 dp.
- Анимация внутри виджета невозможна (RemoteViews без анимации); живой фон удалён как нерабочий.


## Скрывать значок в строке состояния

Тумблер в настройках приложения: **«Скрывать значок в строке состояния»**.

- сервис **не останавливается**, проверки продолжаются;
- уведомление переводится на канал `net_monitor_status_hidden_v1`
  с важностью MIN, без звука и вибрации;
- на HONOR/MagicOS такие «тихие» уведомления обычно не показывают значок
  в строке состояния;
- выключите тумблер и нажмите «Сохранить настройки», чтобы вернуть значок.


## Русские названия городов

Обратное геокодирование берёт только кириллические названия:
Nominatim (`accept-language=ru`) → BigDataCloud (`localityLanguage=ru`) → Geocoder.
Если результат транслитерирован (например, `Gorodskoy Okrug Ivanteevka`) или является
районом/округом, подставляется сохранённое русское имя города.


## Частота обновления города по GPS

В настройках приложения рядом с городом: **2 часа / 4 часа / 8 часов / вручную**.

- GPS-координаты кэшируются; при выбранном интервале город и погода обновляются
  не чаще этого интервала;
- **«вручную»** — GPS не опрашивается, показывается город из поля
  «Город для часов (вручную)» (или последний кэш);
- выбранный город отображается в часах/виджете.


## Публикация в GitHub

Публичная сборка **не содержит** HONOR-шрифтов и иконок: локальная папка
`android/app/src/localHonor/` в `.gitignore`, а код использует fallback-ресурсы
(системный шрифт и собственные векторные иконки). Проверено: `assembleDebug`
без этой папки проходит успешно.

Перед публикацией стоит указать источники данных: погода — Open-Meteo,
обратное геокодирование — Nominatim/OpenStreetMap. Локальный APK с ассетами HONOR
публиковать нельзя.


## Анимация осадков в виджете

- снег: **36 кадров**, 12 остроконечных 6-лучевых снежинок разного размера (мелкие→крупные), разная скорость падения, цикл ~9 с;
- дождь/ливень: 18 кадров, тонкие штрихи;
- морось: 48 кадров, 6 тонких капель: сверху остриё, к земле расширяются и низ полукруглый; нелинейная длина и разная скорость;
- гроза: 18 кадров, дождь + вспышки молнии;
- туман: 14 кадров, медленно плывущие полосы.

Кадры переключает foreground-сервис (только при включённом экране); без сервиса
остаётся статичный первый кадр.


Площадь анимации внутри виджета — **80 dp**; подпись осадков выровнена по дате;
`minHeight` виджета — 120 dp.


## Часы на виджете без сервиса

Минутный `AlarmManager`-тик (`WidgetTickReceiver`) обновляет время на виджете даже
при остановленном foreground-сервисе. Проверено: при остановленном сервисе время
сменилось с 14:15 на 14:16. Будильник восстанавливается после перезагрузки.


## Нативные часы TextClock

Время на виджете теперь рисует `TextClock` (`format24Hour="HH:mm"`), а не текст,
который обновлял сервис. Часы идут сами, без foreground-сервиса и без будильников.
Проверено: 17:16 → 17:17 при системном времени 17:17. Минутный будильник оставлен
только как дополнительное обновление погоды/статуса.


## Анимация «Облачно»

36 кадров, два слоя облаков: дальний слой бледнее и движется медленнее,
ближний — плотнее и быстрее; цикл ~11 секунд. Кадры переключает foreground-сервис.


## Реалистичные облака и луна

Для кода «облачно» виджет рисует сцену программно (Bitmap + RadialGradient):
мягкие облака без видимых кругов, два слоя с разной скоростью, за ними солнце
днём или луна ночью. Фаза луны рассчитывается по текущей дате (синодический
месяц, новолуние 2000-01-06 18:14 UTC), освещённая часть и терминатор
соответствуют фазе; в 80 dp это выглядит как мягкая дымка.


Светило рисуется поверх облаков с «окном» чистого неба: днём солнце, ночью луна;
фаза луны реальная (сейчас тонкий серп ~8%), поэтому добавлены земное сияние и контур,
чтобы серп был виден.


## Расширенная сцена неба

- Область анимации расширена влево на 50%: **120×80 dp** (битмап 384×256).
- Солнце и луна увеличены примерно в два раза.
- Луна: диск с кратерами, потемнением к краю, реальной фазой (эллиптический
  терминатор), земным сиянием и контуром — сейчас тонкий растущий серп ~8%.
- Солнце: тёплый диск с короной и лучами.
