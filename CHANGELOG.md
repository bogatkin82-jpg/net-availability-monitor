# Changelog

## [1.4.0] — 2026-11-11

### Добавлено

- **Android: виджет-часы на главный экран** — время окрашивается по худшему статусу
  сервисов (зелёный/жёлтый/красный), рядом цветная ● и подпись статуса; обновляется
  вместе с проверками, тап открывает приложение. Кнопка «Добавить виджет-часы»
  в настройках (pin widget).
- Виджет системного «Рекомендации YOYO» изменить нельзя — он принадлежит HONOR;
  собственный виджет решает ту же задачу.

### Изменено

- Android: версия 1.4.0 (versionCode 8).


## [1.3.3] — 2026-11-11

### Изменено

- Android: **убраны отдельные уведомления при смене статуса** — остаётся только постоянный
  индикатор в строке состояния (и одна строка в шторке). Раздел «Уведомления» в настройках
  удалён, звук/вибрация больше не используются.
- Учтено, что в HONOR MagicOS стиль значков «Монохром» сам меняет форму индикатора
  (точка/крестик и т.п.); приложение лишь задаёт форму по статусу.


## [1.3.2] — 2026-11-11

### Исправлено

- Android: иконка статуса в строке состояния теперь видна, даже если в системе включено
  «Скрывать тихие уведомления» (`hideSilentStatusBar`): канал уведомления формально не
  «тихий» (ресурс 0.1 с тишины, без звука/вибрации).
- Android: формы иконок стали заметнее — ● всё ок, ▲ нестабильно, ⊘ блокировка
  (жирный знак «запрещено»), ✕ нет связи, ○ нет данных. Цвет в строке состояния задаёт
  системная тема (на HONOR — зелёный), цвет статуса виден в шторке.
- Android: в настройках появилась кнопка «Настройки уведомлений приложения» и пояснение
  про системное скрытие тихих уведомлений.


## [1.3.1] — 2026-11-11

## [1.3.0] — 2026-11-10

### Добавлено

- **iOS-приложение (iPhone, iOS 17+)**: нативное SwiftUI-приложение с теми же
  постадийными проверками DNS → TCP → TLS → HTTP, классификацией
  `ok/degraded/blocked/down/unknown`, журналом инцидентов, настройками и локальными
  уведомлениями. Единый `config.json` (копия в `ios/Resources/`, паритет проверяется
  `tools/check_config.py`), XcodeGen-проект, XCTest-тесты, сборка в GitHub Actions
  на macOS-раннере (`iOS build`).
- iOS: сборка для симулятора без подписи в артефактах и nightly-релизе; инструкция
  по подписи/TestFlight — `docs/ios.md` (нужен Apple Developer Account).
- **Android: индикатор статуса в строке состояния** — постоянная иконка рядом с часами,
  форма которой меняется по статусу (● / ◐ / ⊘ / ✕ / ○); цвет статуса показывается в
  шторке (Android не разрешает цветные иконки строки состояния). Сервис стартует при
  открытии приложения и включается переключателем в настройках.


## [1.2.0] — 2026-11-10

### Добавлено

- **Режим проверок через системный прокси/VPN**: `network.proxy` в `config.json`
  (`direct` — напрямую, по умолчанию; `system` — через системный HTTP-прокси/VPN;
  `http://host:port` — явный прокси). Проверки используют HTTP CONNECT-туннель,
  поэтому TLS/HTTPS идут через прокси с сохранением SNI и проверки сертификата.
- Переопределение без правки конфига: `server.py --proxy system` и переменная
  `NETMON_PROXY` (установщик macOS прокидывает её в LaunchAgent).
- В `/api/state` появился блок `proxy` (`mode`, `active`, `url`), у проверок — поле
  `proxy_used`; индикатор macOS показывает активный прокси в подсказке и меню.
- Android-приложение автоматически использует системный VPN (весь трафик идёт через
  `tun`), поэтому прокси-режим ему не нужен; `network.proxy` им игнорируется.

### Исправлено

- Локальные HTTP-клиенты (трей Windows, тесты, индикатор macOS) обходят системный прокси
  для запросов к `127.0.0.1`, иначе Happ/корпоративный прокси отвечает 502.


## [1.1.0] — 2026-11-10

### Добавлено

- **Подпись релизов**: Android APK/AAB подписываются release-keystore (ключ и пароли — в GitHub Secrets),
  Windows `.exe` и установщик подписываются Authenticode-сертификатом (self-signed, публичный `.cer`
  прикладывается к релизу). Включена проверка подписи в CI.
- **Установщик Windows**: Inno Setup `NetMonitor-Setup-x64.exe` (per-user, ярлыки, опциональный автозапуск,
  деинсталлятор).
- **Nightly-сборки**: ежедневные prerelease-сборки Windows и Android с тегом `nightly`.
- `SHA256SUMS.txt` в релизе; сертификат подписи Windows в релизе.
- README переведён на английский как основной; русская версия — `README.ru.md`.

### Изменено

- Версия 1.1.0 (server.py, Android versionCode 2/versionName 1.1.0, установщик).

## [1.0.0] — 2026-11-10

Первый публичный релиз.

### Добавлено

- Python-бэкенд с постадийными проверками DNS → TCP → TLS → HTTP, классификацией
  `ok/degraded/blocked/down`, журналом инцидентов, историей и JSON API.
- Дашборд (`static/`) с карточками сервисов, sparkline, журналом сбоев с поиском
  и экспортом.
- macOS: индикатор в меню-баре (Swift/AppKit) в режимах overlay/dot/text,
  установщик с LaunchAgents и автозапуском.
- Windows: трей-индикатор, единый `.exe` (PyInstaller), установщик с HKCU Run.
- Android: нативное приложение Kotlin/Compose со своим движком проверок,
  настройками и foreground-уведомлениями.
- Единый `config.json` и `tools/check_config.py` для валидации и паритета настроек.
- CI: конфиг, Python-тесты, сборка macOS-индикатора, Windows `.exe`, Android APK.
